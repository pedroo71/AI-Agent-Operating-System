# SEC-006 — Hook SessionStart arranca o servidor sem restringir a interface

Severidade: high (é este caminho que põe o servidor em 0.0.0.0; mesmo impacto que SEC-001)
Dono: tech-lead
Localização: scripts/start-agent-os.mjs (chamada a `spawn` de `next dev -p 4100`)
Estado: Verified

## Descrição
O script chama o binário do Next diretamente com `['dev','-p','4100']`, sem `-H 127.0.0.1`; corrigir só o package.json não o cobre.

## Passos para reproduzir
Ler o script (chamada a `spawn`). Verificado e OK: sem input externo nos argumentos, caminhos fixos relativos ao repo, `stdio` para ficheiro de log em `os.tmpdir()`; a entrada em `.claude/settings.json` usa `$CLAUDE_PROJECT_DIR` entre aspas e timeout de 15 s.

## Impacto
Ver SEC-001.

## Correção recomendada
Acrescentar `'-H','127.0.0.1'` aos argumentos. Opcional: testar a porta também em ::1.

## Evidência
`spawn(process.execPath, [nextBin, 'dev', '-p', String(PORT)], …)`.

## Fix
2026-11-17, tech-lead: `scripts/start-agent-os.mjs` passa `'-H', '127.0.0.1'` ao `next dev`. A porta já
é testada em 127.0.0.1, que é o único endereço onde o servidor passa a escutar. Pronto para reteste.

## Reteste (2026-11-17)
O script passa `-H 127.0.0.1` ao `spawn`; o servidor reiniciado pelo hook escuta só em 127.0.0.1. Verified.
