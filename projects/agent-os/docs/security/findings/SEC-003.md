# SEC-003 — Dependências com avisos no npm audit

Severidade: low (vitest crítico é só dev; postcss do Next só processa o CSS do próprio projeto)
Dono: backend-dev
Localização: projects/agent-os/package.json
Estado: Accepted risk (tech-lead, 2026-11-17)

## Descrição
`npm audit`: 9 avisos (2 críticos, 5 altos, 2 moderados). Críticos/altos: `vitest` -> `tinypool` (prototype pollution/RCE), `vite`/`fdir`/`picomatch` (ReDoS), `postcss` embebido em `next` (XSS no stringify, leitura de .map). Com `--omit=dev`: 2 (next -> postcss).

## Caminho usado?
Vitest/vite/tinypool: só ao correr testes, com código nosso; não afeta o servidor. PostCSS: só em build, com CSS próprio. Não explorável neste uso, mas convém limpar.

## Correção recomendada
`npm audit fix` (sem --force) e reavaliar; atualizar `next` e `vitest` quando o utilizador aprovar (versão maior: registar em PLAN.md § Changes).
