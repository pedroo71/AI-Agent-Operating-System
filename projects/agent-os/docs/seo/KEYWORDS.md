# Agent OS — Palavras-chave e terminologia

## Nota
O Agent OS é uma ferramenta interna, local (`localhost:4100`), e **não deve ser indexada**. Não há
pesquisa de palavras-chave nem objetivo de tráfego orgânico. Este documento serve só para manter a
terminologia da interface consistente (pt-PT).

- Página única: `/`. Palavra-chave principal (só para `<title>`/H1): "Agent OS".
- Intenção de pesquisa: nenhuma (uso direto pelo utilizador).

## Vocabulário da interface (usar sempre estes termos)
| Conceito | Termo na UI | Evitar |
|---|---|---|
| Agent | agente | bot |
| Session | sessão | seção |
| Team | equipa | time |
| Task | tarefa | ticket |
| Project | projeto | projecto (acordo ortográfico: "projeto") |
| Memory | memória | — |
| Timeline | linha temporal | timeline |
| Feed | feed (de atividade) | — |
| Live | ao vivo / em direto | live |
| Active / idle / finished | ativo / inativo / terminado | — |
| Pending / in progress / done | pendente / em curso / concluída | — |
| File | ficheiro | arquivo |
| Tool call | chamada de ferramenta | — |
| Minimize / close | minimizar / fechar | — |
| Start button | Início | Start |
| Deliverable | entregável | — |
| Loading | a carregar | carregando |
| Connecting | a ligar | conectando |

Regras pt-PT: gerúndio brasileiro proibido ("a carregar", não "carregando"); "ecrã", não "tela";
"clicar" ou "abrir" ok; tratamento neutro/impessoal, sem "você".
