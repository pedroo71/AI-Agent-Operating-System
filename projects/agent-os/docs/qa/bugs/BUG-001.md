# BUG-001 — Em `npm run dev` o indicador do Next tapa o botão Início

- **Severidade:** minor
- **Dono:** backend-dev (`next.config.ts`; alternativa: frontend-dev desloca o botão)
- **Estado:** Verified
- **Encontrado em:** build de 2026-11-16, Chrome 1280x800 e 375x812, `next dev`

## Passos para reproduzir
1. `npm run dev` em `projects/agent-os` e abrir http://localhost:4100 (ou a porta usada).
2. Esperar que a página hidrate (~1 s).
3. Tentar clicar no centro do botão **Início** (canto inferior esquerdo da barra de tarefas).

## Esperado
O botão Início abre o menu "Escolher sessão".

## Observado
O botão circular "N" do Next.js (`<nextjs-portal>`) fica por cima do centro do botão e intercepta o clique.
O seletor de sessão só se alcança clicando na parte direita do botão. Em 375 px a sobreposição é maior.
Em `next build` + `next start` o problema não existe (verificado com `QA_PROD=1`).

## Evidência
- `npx playwright test dev-overlay.spec.ts` falha: "o centro do botão Início está tapado por outro elemento" (`document.elementFromPoint` no centro do botão não pertence a `.start-btn`).
- Screenshot: `test-results/dev-overlay.png` (gerado pelo teste; apagado em cada execução).
- Playwright: `<nextjs-portal></nextjs-portal> from <script data-nextjs-dev-overlay="true"> subtree intercepts pointer events`.

## Sugestão (não vinculativa)
`devIndicators: false` em `next.config.ts`, ou reposicionar o indicador (`devIndicators: { position: 'bottom-right' }` no Next 15.5 — verificar), já que `npm run dev` é o comando documentado.

## Fix
- **Causa:** o indicador de desenvolvimento do Next (botão "N", `<nextjs-portal>`) é renderizado no canto inferior esquerdo, sobre o botão Início.
- **Alteração:** `devIndicators: false` em `next.config.ts`. Só afeta `next dev`; produção não muda.
- **Ficheiros:** `projects/agent-os/next.config.ts`.
- **Nota:** o servidor de dev reinicia ao mudar `next.config.ts`; pronto para reteste.

## Reteste
- **Resultado:** Verified
- Reteste 2026-11-16: `npx playwright test dev-overlay.spec.ts` passa (o centro do botão Início já não está tapado) e a suite completa em modo dev passa 47/47.
