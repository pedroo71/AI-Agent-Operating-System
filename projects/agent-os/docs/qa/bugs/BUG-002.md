# BUG-002 — A Linha temporal mostra os eventos do mais recente para o mais antigo

- **Severidade:** minor
- **Dono:** frontend-dev
- **Estado:** Verified
- **Encontrado em:** build de 2026-11-16, desktop 1280x800

## Passos para reproduzir
1. Correr a app com `CLAUDE_HOME=fixtures/claude-home` (ou a cópia usada pelos testes).
2. Na janela **Agentes**, clicar no cartão `backend-dev`.
3. Ler as horas dos eventos na janela **Linha temporal**, de cima para baixo.

## Esperado
`DESIGN.md` § Janelas: "Linha temporal (por agente) — Eventos **cronológicos**". A API também devolve ordem ascendente. O primeiro evento no topo deveria ser o mais antigo (10:00:20) e o mais recente no fim.

## Observado
Ordem descendente: 10:00:24, 10:00:23, 10:00:22, 10:00:21, 10:00:20 (`components/windows/TimelineWindow.tsx` faz `[...list].reverse()`).

## Evidência
- `npx playwright test ui.spec.ts -g UI-08`: `datetime` dos `.event-row` = `[...24, ...23, ...22, ...21, ...20]`, esperado ascendente.
- Screenshot de teste: `test-results/mobile-timeline.png` (execução móvel) mostra 10:00:24 no topo.

## Nota
Pode ser uma escolha deliberada (mais recente no topo, como o Feed). Nesse caso, o tech-lead deve atualizar `DESIGN.md` e fecho o bug como "Closed (por design)"; o teste UI-08 passa a esperar ordem descendente.

## Fix
- **Causa:** `TimelineWindow` invertia a lista (`[...list].reverse()`), copiando o Feed (mais recente no topo), contra o DESIGN ("cronológicos").
- **Alteração:** a lista mostra-se em ordem ascendente (mais antigo no topo, mais recente no fim). Para continuar útil ao vivo, a lista segue o fim enquanto o utilizador estiver a menos de 40 px do fim; se subir para ler, não é arrastada. Verificado em Chrome: `datetime` ascendente (20 linhas) e `scrollTop` no fim ao abrir.
- **Ficheiros:** `components/windows/TimelineWindow.tsx`
- **Nota para o teste UI-08:** esperar ordem ascendente. O Feed mantém mais recentes no topo (por design).

## Reteste
- **Resultado:** Verified
- Reteste 2026-11-16: UI-08 passa; `datetime` dos eventos da Linha temporal em ordem ascendente (10:00:20 ... 10:00:24).
